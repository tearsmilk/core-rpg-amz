# coreshaders

Плагин и ресурспак (через Nexo) для "окон в другой мир": куб 16x16x16 или плоскость 16x16 на грани блока, в которых
видна панорама 360 градусов. Картинка зависит от направления взгляда (как у портала в Энд), а не от UV грани:
повернул камеру - панорама стоит на месте в мире, смотришь в куб как в окно.

Автор: tearsmilk. Сервер: Leaf 1.21.11 (Paper API), Java 21, Nexo.

## Что внутри

- `pack/assets/...` - файлы ресурспака, копируются в `plugins/Nexo/pack/assets/`:
  - `minecraft/shaders/core/rendertype_item_entity_translucent_cull.{vsh,fsh}` - ванильные 1.21.11 + наш хук
    (одна строка в main у каждого). Остальное в шейдере не тронуто.
  - `coreshaders/shaders/include/cs_vertex.glsl`, `cs_fragment.glsl` - сам эффект.
  - `coreshaders/textures/item/panorama/<картинка>.png` - панорамы 1024x512 (эквидистантная проекция),
    `<картинка>_glow.png` - 16x16 спрайт рамки плоскости.
  - `coreshaders/models/item/{cube,plane}_<картинка>.json`, `coreshaders/items/{cube,plane}_<картинка>.json`.
- `src/` - плагин (Gradle), `build/libs/coreshaders-1.0.0.jar` после сборки.
- `tools/panoramas.py` - рисует панорамы процедурно (numpy + PIL) и пишет модели/предметы.
- `tools/glsl_check.py` - компиляция и линковка шейдера glslangValidator (ваниль + наш, #version 330 и 410).
- `tools/preview.py` - превью настоящим шейдером (moderngl, EGL) в `preview/`.

Картинки: `sky_sea` (небо с облаками над бирюзовым морем, как в видео), `space` (туманность и звезды),
`nether` (лавовое море, красный туман, светокамень), `aurora` (северное сияние над снегом), `end` (звездное поле
в цветах портала Энда).

## Как работает шейдер

- Предметы рисуются ItemDisplay с компонентами `item_model = coreshaders:<форма>_<картинка>` и
  `custom_model_data.colors = [цвет]`. Цвет приходит в шейдер как цвет вершины и умножает картинку (белый - оригинал).
  Менять цвет и картинку можно с сервера без пересборки пака.
- Наши спрайты узнаются по подписи в строке 0: тексель (0,0) = (61,203,147,3), тексель (1,0) = (K,147,203,3),
  K = номер картинки 1..5 (рамка - 16+K). Альфа 3 ниже ванильного порога 0.1, без хука их не видно.
  Угол квада берется из gl_VertexID % 4 (порядок вершин запеченной модели), отсюда начало спрайта в атласе.
- Position у сущностей в 1.21.11 - относительно камеры в мировых осях (поворот камеры в ModelViewMat), поэтому
  normalize(Position) во фрагменте - мировое направление взгляда. u = atan(d.z, d.x)/2pi + 0.5, v по высоте.
  Горизонт опущен на 26 градусов (CS_HORIZON), чтобы у блока у ног было видно и небо, и море.
- Выборка - билинейная вручную через texelFetch (без мипов и без шва на u = 0/1), строка 0 не читается.
- Анимация от GameTime (целые циклы за 1200 с, без скачков): облака покачиваются, рябь моря, мерцание звезд,
  колыхание сияния, пульс лавы, медленное вращение космоса/Энда. По краям граней - мягкий светящийся обод,
  у плоскости еще рамка-свечение 22x22 px вокруг панели.
- Освещение мира не влияет: окно светится само. Туман - ванильный.

## Команды

Все команды: право `coreshaders.admin` (по умолчанию у опов). Алиас `/cs`.

| Команда | Что делает |
|---|---|
| `/cs give [игрок] [cube\|plane] [картинка] [цвет]` | выдать жезл (огненный стержень) |
| `/cs color <#RRGGBB\|имя\|r,g,b>` | цвет эффекта под прицелом |
| `/cs image <картинка>` | картинка эффекта под прицелом |
| `/cs shape <cube\|plane>` | форма эффекта под прицелом |
| `/cs remove` | убрать эффект под прицелом |
| `/cs info` | форма, картинка, цвет, блок, грань |
| `/cs list` | картинки, цвета и эффекты в радиусе 32 |
| `/cs removeall <радиус\|all>` | убрать эффекты в радиусе (до 512) или `all` - все в мире; без аргумента только подсказка, из консоли - все во всех мирах |
| `/cs reload` | перечитать config.yml |

"Под прицелом" - луч до `max-distance` (8 блоков), блоки перед эффектом его закрывают.

### Жезл

- ПКМ по блоку - поставить: куб - в соседний блок у кликнутой грани (там должен быть воздух), плоскость - на
  кликнутую грань (с отступом 0.015, чтобы не мерцало). ПКМ по кубу-эффекту ставит следующий куб рядом,
  ПКМ по плоскости только подсказывает, что место занято. Плоскости нужен блок за ней (не воздух).
- ЛКМ по эффекту - убрать (по хитбоксу Interaction или лучом, если кликнул по стене рядом с плоскостью).
- Shift + ПКМ - следующая картинка жезла, Shift + ЛКМ - сменить форму жезла (cube/plane).
- Форма, картинка и цвет жезла - в PDC предмета и в описании.

Эффекты - постоянные ItemDisplay с PDC (`coreshaders:shape`, `image`, `color`, `face`, `block`, `link`) и
Interaction-хитбоксом (`coreshaders:owner`). Переживают рестарт. Хитбоксы без дисплея удаляются (при загрузке
чанка и раз в 30 с), дисплею без хитбокса хитбокс создается заново.

## config.yml

`images` - список картинок, должен совпадать с паком. `image-names` - русские названия. `defaults` - форма,
картинка и цвет жезла по умолчанию. `max-distance`, `plane-offset`, `brightness`. `colors` - именованные цвета
(есть русские). `messages` - все сообщения (MiniMessage, только короткие дефисы).

## Сборка

```
cd coreshaders
./gradlew --offline build          # тесты + build/libs/coreshaders-1.0.0.jar
python3 -I tools/panoramas.py      # перерисовать панорамы, модели, предметы (около минуты)
python3 -I tools/glsl_check.py     # glslangValidator: компиляция и линковка
pip install moderngl && python3 -I tools/preview.py   # превью в preview/
```

## Деплой

1. Скопировать содержимое `coreshaders/pack/assets/` в `plugins/Nexo/pack/assets/` (папки `coreshaders` и
   `minecraft/shaders/core`). Других шейдеров на rendertype_item_entity_translucent_cull на сервере нет - файл наш.
2. Положить `build/libs/coreshaders-1.0.0.jar` в `plugins/`.
3. Рестарт сервера (Nexo пересоберет и раздаст пак). Если включена обфускация пака Nexo - проверить, что
   `assets/coreshaders/items/*.json` остались с теми же именами (плагин ссылается на `coreshaders:cube_sky_sea` и т.д.).
4. В игре: `/cs give`, ПКМ по блоку.

Добавить картинку: функция в `tools/panoramas.py` (+ запись в IMAGES, GLOW), цвет рамки в `CS_GLOW` в
`cs_fragment.glsl` и проверка `kind <= 5` / `<= 21` там же, затем строка в `images` конфига.
