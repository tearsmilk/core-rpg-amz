# starmap — карта-радар (клиентский модуль)

**M** — открыть/закрыть карту. Это «навигационный радар» в духе приборной панели: почти чёрное полупрозрачное окно
по центру (2/3 экрана) с тонкой бирюзовой рамкой и тёмной шапкой («НАВИГАЦИОННЫЙ РАДАР · <карта>» слева,
`[M] закрыть  [R] центр` справа — по ним можно щёлкнуть). Слева — круглый экран: четыре тонких сглаженных кольца
дальности с подписями в блоках у оси «север», едва заметная сетка, тонкие оси, риски курса через 10° (длинные — через
30°) снаружи кольца и крупные буквы С/В/Ю/З; плавный клин развёртки с мягким квадратичным послесвечением и яркой
передней линией (контакты чуть вспыхивают, когда луч проходит по ним); строки развёртки поверх окна. Окно
появляется с лёгкой «упругостью» и затемняет мир.

Всё рисуется в настоящих пикселях экрана (при любом «Масштабе интерфейса»): кольца, сетка, риски, клин, рамка окна и
значки растеризуются со сглаживанием один раз — при смене размера окна — в текстуры; за кадр только выводятся эти
текстуры (клин — с поворотом), значки, текст и строки развёртки.

На карте:

- **блоки вокруг** — вид сверху на то, что прогружено у клиента (в пределах прорисовки), но не сплошной заливкой:
  мягкие полупрозрачные «кляксы» того, что **выделяется**. Ровная земля (самая частая высота верхних блоков, если она
  занимает больше трети круга) почти не видна — едва заметный контур прогруженного; чем дальше столбец по высоте от
  неё, тем ярче. Цвет — по высоте относительно тебя: выше — зелёный, ниже — бирюзовый/голубой. В космосе ровной
  земли нет — астероиды и станции видны целиком; при мелком масштабе берётся самый высокий из нескольких замеров,
  поэтому маленький астероид не пропадает;
- **ты** — светлая стрелка по курсу взгляда (с расходящимся кольцом); увёл вид — стрелка на ободе показывает, где ты;
- **корабли** (с сервера) — ромбы: твой — голубой, чужие — янтарные, короткая черта — курс корабля; за краем обзора —
  ромбик на ободе;
- **игроки** — сиреневые точки. С сервера (модуль `starmap`), а без него — те, кого видит сам клиент;
- **твои точки** — розовые ромбы-контуры с именем (выбранная — светлее).

У каждого контакта — подпись («Корабль · имя», «Игрок · имя», «Твой корабль «имя»»), под ней — разница высот со
знаком (`+12`, `−30`), и **ножка высоты**: значок поднят над своим местом, если цель выше тебя, опущен — если ниже.
Наведи мышь — подсказка в стиле радара поверх всего: тёмная рамка цвета цели, «имя · что это», дистанция, высота
(у чужого корабля — ещё владелец).

## Управление

| | |
|---|---|
| **M** | открыть / закрыть (не срабатывает, пока открыт чат или другое окно; клавиша — `open_key`) |
| колёсико, **+** / **−**, кнопки «+» «−» | масштаб: радиус обзора 32…1024 блока (в свободном виде колёсико приближает к курсору) |
| тянуть левой кнопкой | сдвинуть вид (вид перестаёт следовать за тобой) |
| **R**, кнопка «К СЕБЕ» | вернуть вид к себе (`recenter_key`) |
| щелчок левой по пустому месту | поставить точку («Точка N», высота — верхний блок там или твоя) и выбрать её |
| щелчок левой по точке | выбрать (в боковой панели — имя, его можно исправить в поле; Enter — готово) / снять выбор |
| правая по точке, **Delete**, кнопка «УДАЛИТЬ ТОЧКУ» | удалить точку |
| **Esc** | закрыть |

Правая колонка (как на макете): **ТЕЛЕМЕТРИЯ** — X, Y, Z, курс (градусы и сторона света), скорость (блоков в
секунду); **ДИАПАЗОН** — масштаб (радиус обзора; кнопки `[−] [+]`), число целей и точек, режим вида; **ТОЧКА** —
выбранная точка: поле имени (щёлкни и печатай, Enter — готово), координаты, расстояние, `[удалить]`; без выбора —
подсказка, как поставить; **ЦЕЛИ** — корабли и игроки по расстоянию, имена цветом значка; внизу — условные знаки и
подсказки по управлению. Высоты блоков колонки не зависят от того, что в них, — при смене данных ничего не прыгает;
в маленьком окне (720p) условные знаки убираются, подсказки ужимаются до двух строк. Под экраном радара: слева —
курсор (место, высота блока под ним и расстояние), справа — ход сканирования блоков и связь с сервером («связи нет»
мигает, если серверного модуля нет или он молчит).

Точки хранятся отдельно для каждого сервера и карты: `.minecraft/hoka_odyssey/data/starmap/waypoints/<сервер>__<карта>.json`
(`{"waypoints": [{"name", "x", "y", "z"}]}`, не больше 256). Имя карты присылает сервер; без серверного модуля —
измерение игры (`minecraft_overworld` и т.п.).

По желанию — **метки точек на экране без карты** (`hud_waypoints = true`, по умолчанию выкл.): ромбик с именем и
расстоянием вверху экрана, когда точка впереди (±60° от взгляда).

## Почему своё окно, а не houi

Окна houi (JSON-раскладка, `/houi reload`) хороши для меню с кнопками и списками, но радар — это рисование каждый
кадр по данным клиента: развёртка, масштаб колёсиком, перетаскивание, щелчок в произвольную точку карты, слой блоков
из прогруженных чанков (своя текстура). Узлов для этого в houi нет, а гонять данные через сервер ради каждого кадра
нельзя. Поэтому окно — свой `Screen` клиентского модуля (`RadarScreen`), нарисованный `GuiGraphics`. Классы
окон ядра (`ink.hoka.odyssey.client.ui.*`) — не API модулей, поэтому не используются; от окон houi взяты затемнение
мира без размытия и появление с упругостью «back». GUI игры умеет только прямоугольники и текстуры, поэтому тонкие
сглаженные линии рисует свой растеризатор (`Raster`: покрытие по расстоянию от пикселя до фигуры, без java.awt —
на macOS он может зависнуть вместе с GLFW) в текстуры `GlTex` (сглаживание LINEAR).

## Шрифт

Текст радара — **DejaVu Sans Mono** (свободная лицензия Bitstream Vera + public domain, текст — `assets/starmap/font/LICENSE.txt`),
урезанный до латиницы, кириллицы и знаков (26 КБ), лежит **в jar самого модуля**. Буквы растеризуются
stb_truetype (входит в LWJGL игры) прямо в нужном размере в пикселях экрана, с лёгким ореолом, и складываются
в атлас-текстуру — гладкий текст без пиксельного масштабирования.

Почему не `Style.withFont(...)`: шрифты Minecraft регистрируются только перезагрузкой ресурсов (resource reload),
а мод Hoka Odyssey её нарочно не делает (файлы с сервера идут прямо в текстуры) и не даёт модулям API шрифтов.
Сервер через clientmods может раздать любой файл (`api.putFile` + `publishFiles`, клиент читает `ctx.file`/
`ctx.onFile`), но зарегистрировать его как шрифт игры модуль не может. Поэтому серверу ничего публиковать не нужно:
шрифт приезжает вместе с jar модуля. Нет шрифта или stb — тихо рисуется шрифтом игры `minecraft:uniform`.
`mono_digits = false` — сразу шрифт игры.

## Как устроен слой блоков

`Terrain`: сетка высот 1024×1024 столбцов (±512 блоков вокруг места, где её начали; ушёл дальше 256 блоков —
собирается заново вокруг тебя), на столбец — высота самого верхнего не-воздуха. Чанки читаются по кругу от центра
**понемногу за кадр** (`scan_budget_ms`, 3 мс) — в потоке отрисовки, потому что мир клиента из другого потока читать
нельзя; так кадр не стоит дольше бюджета. Пустые секции («только воздух») пропускаются целиком, поэтому космос почти
ничего не стоит. Пока карта открыта, чанки перечитываются по кругу (новые блоки).

`TerrainView` строит из высот картинку экрана радара в половинном разрешении (2 пикселя на тексель, сглаживание при
выводе): гистограмма высот → «земля», прозрачность по разнице с ней, цвет по высоте относительно тебя, размытие 3×3,
мягкий край круга. Перестраивается при смене масштаба сразу, а при движении, новых блоках или смене твоей высоты —
не чаще раза в 120 мс; между перестройками картинка просто сдвигается вслед за видом.

## Настройки

`.minecraft/hoka_odyssey/data/starmap/config.properties` (создаётся сам, с комментариями):
`open_key` (`key.keyboard.m`), `recenter_key` (`key.keyboard.r`), `default_range` (256), `terrain` (true),
`scan_budget_ms` (3), `sweep_seconds` (4), `flicker` (true), `mono_digits` (true — свой шрифт радара), `client_players` (true — без
серверного модуля показывать игроков, которых видит клиент), `hud_waypoints` (false), `hud_waypoints_distance` (5000).

## Протокол (канал модуля `starmap`, big-endian, как `DataOutputStream`)

Клиент → сервер:

| op | Содержимое |
|---|---|
| 1 — карта открыта/закрыта | `u8 op, u8 open` (1 — открыта, 0 — закрыта). Пока открыта — повтор раз в 5 с; сервер без повтора 15 с (`open-timeout-seconds`) считает её закрытой |
| 2 — «на какой я карте» | `u8 op` — при входе и смене мира (сервер отвечает не чаще раза в секунду) |

Сервер → клиент:

| op | Содержимое |
|---|---|
| 1 — контакты | `u8 op, u8 version (1), UTF map, i32 shipCount`, на корабль `UTF id, UTF name, UTF owner, u8 flags, f64 x, f64 y, f64 z, f32 yaw`; затем `i32 playerCount`, на игрока `i64 uuidMost, i64 uuidLeast, UTF name, f64 x, f64 y, f64 z, f32 yaw, u8 flags` |
| 2 — имя карты | `u8 op, UTF map` |

Флаги корабля: бит 0 — мой, 1 — летит, 2 — я пилот, 3 — спрятан. Флаги игрока: бит 0 — пилотирует корабль.
`yaw` — градусы Minecraft (0 — на юг, +Z; 90 — на запад). Сервер шлёт op 1 сразу после «открыта» и дальше раз в
`period-ticks` (10 — 2 раза в секунду), только пока карта открыта.

Клиент проверяет ввод: не больше 4096 кораблей/игроков и не больше, чем помещается в длину сообщения; строки
обрезаются до 64 символов, управляющие символы и `§` выкидываются; нечисловые и огромные (>1e8) координаты
отбрасываются; незнакомые op — пропускаются (новая версия сервера). Данные старше 3 с считаются устаревшими.

## Сборка

Нужны только обычные крючки ядра (`onTick`, `onHud`, `onMessage`, `send`) — собирается и против jar мода 0.17, и
против исходников ядра:

```bash
cd hoka-odyssey/client-modules
JAVA_HOME=/usr/lib/jvm/java-25-openjdk-amd64 ./gradlew build --max-workers=1 \
  -Porg.gradle.java.installations.paths=/usr/lib/jvm/java-25-openjdk-amd64 \
  -Phoka.core.jar=/путь/к/hoka-odyssey-0.17.0.jar
```

Результат — `build/clientmods/starmap.jar` → на сервер в `module/clientmods/jars/`, затем `/hoclient reload`.
Серверная пара — `hoka-odyssey/starmap` (`starmap/build/libs/starmap.jar` → `module/`).

## Ограничения

- Блоки — только то, что прогружено у клиента (прорисовка); дальше — пусто.
- Курс стоящего (не летящего) корабля сервер вычисляет по «носу» чертежа (`forward`) — если в чертеже нос не задан,
  курс 0 (на юг).
- Корабли — только с серверным модулем `starmap` и модулем `ships`; без них — ты, игроки рядом (что видит клиент) и
  точки.
- Точки — только у себя (на сервер не уходят и другим игрокам не видны).
