# spaceflight — живая невесомость в вакууме (клиентский модуль, мод 0.17+)

Пока сервер говорит «ты в вакууме», игрок летает как в настоящем космосе:

- **инерция** — ни сопротивления воздуха, ни «ванильного» падения: толкнулся — летишь, пока что-то не остановит;
- **тяготение** — от тел, которые прислал сервер, по закону 1/r² (общая библиотека `spacephys`, та же, что у
  сервера): рядом с планетой тянет к ней, можно выйти на орбиту;
- **тяга ранца** — W/S вперёд/назад, A/D вбок, пробел/shift вверх/вниз — по осям **взгляда** (а не по горизонту),
  `thrust` б/с²; стоя на блоке — обычный шаг и прыжок от поверхности;
- **свободная камера** — мышь вращает взгляд в своих осях, крен на 360° — Z/C (настраивается); можно сделать петлю
  через верх. Прицел и ломание блоков следуют за взглядом.

Вне вакуума камера плавно возвращается «в горизонт», дальше всё как обычно. При выключении модуля, смене мира
и возрождении всё восстанавливается.

## Настройки

`.minecraft/hoka_odyssey/data/spaceflight/config.properties` (создаётся сам, с комментариями): `thrust`,
`roll_speed`, `roll_left`, `roll_right`, `ground_grip`, `walk_speed`, `jump_speed`, `max_speed`, `upright_rate`.
Клавиши крена — имена Minecraft (`key.keyboard.q`, `key.mouse.4` …). По умолчанию Z/C, потому что Q и E в игре
уже заняты (выбросить предмет, инвентарь).

## Протокол (сервер → клиент, канал модуля `spaceflight`, big-endian)

| op | Содержимое |
|---|---|
| 1 — тела | `u8 op, i32 count`, на тело `f64 x, y, z, mu, radius, softening` (блоки, μ — блоки³/с²). `softening > 0` — малое тело (Пламмер), иначе планета радиуса `radius` |
| 2 — физика | `u8 op, u8 on` (1 — включить невесомость, 0 — выключить) |

Ввод проверяется: не больше 4096 тел, длина сообщения, конечные числа. Новые тела заменяют старые целиком.

## Сборка

Модулю нужны хуки камеры мода 0.17 (`onMouse`, `onCamera`) — рядом файл `requires-camera-api`. Исходники мода 0.17
не публикуются, поэтому сборка идёт против его jar (в репозиторий jar **не** кладётся — только путь):

```bash
cd hoka-odyssey/client-modules
JAVA_HOME=/usr/lib/jvm/java-25-openjdk-amd64 ./gradlew build --max-workers=1 \
  -Porg.gradle.java.installations.paths=/usr/lib/jvm/java-25-openjdk-amd64 \
  -Phoka.core.jar=/путь/к/hoka-odyssey-0.17.0.jar        # или переменная окружения HOKA_CORE_JAR
```

Результат — `build/clientmods/spaceflight.jar` (классы `spacephys` вшиты). Положить на сервер в
`module/clientmods/jars/`, затем `/hoclient reload`. Старый вариант `-Phoka.core.dir=...` (исходники ядра)
по-прежнему работает; ядро без `onCamera` модуль пропускает.
