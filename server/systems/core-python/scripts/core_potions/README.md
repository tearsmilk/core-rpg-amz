# core_potions (ポーション) — механика зелий Nexo

| Зелья | Малое | Среднее | Большое | Кто пьёт |
|---|---|---|---|---|
| Красные — здоровье | +10 | +25 | +50 | все |
| Синие — мана | +10 | +25 | +50 | маги (MAGE, WARLOCK, WIZARD) |
| Зелёные — энергия | +10 | +25 | +50 | классы с энергией (остальные) |

Не тот класс или полная шкала — зелье не выпивается и остаётся в руке, над хотбаром причина.

Вид зелий — Nexo (`plugins/Nexo/items/skulpt/basic_potions.yml`), механика — эта Python-система.
Система написана в **японском режиме** (`言語: 日本語` в `manifest.yml`, см. раздел «Японский режим» README core-python
и `docs/japanese-mode-vocabulary.md`): весь код `main.py` — японскими знаками, по-английски остались только строки
(полные имена классов MMOCore, имена методов в `甘酒.呼ぶ(…)`, ключи yml/PDC). Поведение — то же, что у прежней
английской версии (она лежит эталоном в `src/test/resources/ja/core_potions_english_main.py`; `JapaneseModeTest`
прогоняет обе по одному сценарию). `potions.yml` не менялся.
Зелья описываются в `potions.yml` по id предмета Nexo: эффекты, временная прибавка к макс. здоровью (сердцами,
можно 3 — ванильный «прилив здоровья» умеет только по 2), оставлять ли бутылку, сообщение над хотбаром.

- Прибавка к здоровью — временный модификатор `max_health`; повторный глоток продлевает срок; после перезахода
  возвращается на оставшееся время (срок хранится в данных игрока).
- Бутылка не остаётся (`keep-bottle: false`).
- `/cpotions list|reload` (алиас `/ポーション`), право `corepotions.admin`.

Проверено ботом на mc-test: бутылки нет, регенерация 1 мин, макс. здоровье 20 → 26, после перезахода 26,
по истечении срока снова 20.
Японская версия проверена ботом на mc-skilltest (`/home/user/mc-bot/pj_potions.js`, тот же сценарий для английской
и японской версии, результаты совпали): полное здоровье — отказ и сообщение, +10 здоровья без бутылки, тестовое
зелье с `effects` + `health-boost` (регенерация, макс. здоровье 20 → 26, после перезахода 26, по истечении 20),
`keep-bottle: true` — бутылка, чужое зелье — ванильная бутылка, мана/энергия по классам MMOCore, `/cpotions list|reload`
и алиас `/ポーション`.
