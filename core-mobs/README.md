# core-mobs — мобы, лут и регионы спавна для Amazake

Система (`.azs`) для ядра [Amazake](https://github.com/tearsmilk/amazake) (Paper 1.21.11).

- **Регионы спавна любой формы.** Топориком ставятся точки полигона, от 3 до 256. Контур подсвечивается зелёными
  частицами. У каждого региона свой список мобов с весами, лимит живых мобов, интервал спавна и радиус деспавна.
- **Свои мобы из `mobs.yml`.** Здоровье, урон, скорость, броня, размер, снаряжение, постоянные эффекты, эффекты при
  ударе, урон стрел, опыт, защита от солнца.
- **Лут из инвентаря.** Кладёте предметы в инвентарь и сохраняете их командой. Предметы пишутся со всеми NBT
  (компонентами). Шанс и количество каждого предмета настраиваются в файле.
- **Команды:** призыв, список, выдача предмета из лута, яйцо призыва, перезагрузка.

## Сборка и установка

```bash
./gradlew azs
```

Файл `build/libs/core-mobs.azs` кладётся в `systems/` сервера, затем в консоли:

```
amazake system enable core-mobs
```

## Как сделать регион

1. `/mobs wand` — выдаёт топорик (золотой, с меткой; обычный золотой топор не сработает).
2. **ЛКМ по блоку** ставит точку, **ПКМ** убирает последнюю, **Shift + ПКМ** сбрасывает выделение. Точки ставятся по
   контуру, по порядку обхода. Блоки, через которые проходит граница, входят в регион.
3. `/mobs region create <имя>` — создаёт регион. Высота: от самой низкой точки до самой высокой плюс
   `regions.default-height` (5 блоков). Менять её — `/mobs region expand <имя> up|down <блоков>`.
4. `/mobs region addmob <имя> <моб> [вес]` — кто спавнится. Чем больше вес, тем чаще.
5. При желании настроить: `/mobs region set <имя> <параметр> <значение>`.

Пока в руке топорик, видно своё выделение и все регионы рядом. Чтобы видеть регион без топорика:
`/mobs region show <имя>` (ещё раз — выключить). Частицы видит только сам игрок.

| Параметр `set` | Что | По умолчанию |
|---|---|---|
| `spawn on/off` | спавн включён | on |
| `interval <сек>` | как часто регион пробует заспавнить | 10 |
| `max-alive <n>` | сколько мобов региона живо одновременно | 10 |
| `amount <n или a-b>` | сколько за раз | 1 |
| `player-radius <блоков>` | регион работает, только если игрок не дальше этого от границы | 48 |
| `min-distance <блоков>` | моб не появляется ближе этого к игроку | 6 |
| `despawn-radius <блоков>` | моб, отошедший от границы дальше этого, пропадает; `-1` — выключено | 5 |

Мобы появляются на твёрдом блоке, где над ним два свободных блока, в пределах высоты региона. Чанки ради спавна не
грузятся. Мобы регионов не сохраняются в мир: выгрузился чанк или перезапустился сервер — регион заспавнит новых.
Мобов из команды и яйца это не касается: они остаются в мире, как обычные.

## Лут

1. Положите в инвентарь предметы, которые должны падать с моба (любые, с NBT, зачарованиями, предметами других
   плагинов). Топорик и яйца призыва в лут не попадают.
2. `/mobs drops save <моб>` — заменить лут моба, `/mobs drops add <моб>` — добавить к нему.
3. Откройте `systems/core-mobs/drops/<моб>.yml` и поставьте шансы и количество:

   ```yaml
   items:
     '1':
       preview: diamond_sword x1 «Меч»   # подпись для вас
       chance: 25.0                      # шанс в процентах, можно 0.5
       amount: '1'                       # число или диапазон 1-3
       item: rO0ABXNy...                 # сам предмет, не трогать
   ```
4. `/mobs reload`.

Каждый предмет проверяет свой шанс отдельно. Ванильный дроп моба по умолчанию выключен (`vanilla-drops: false`).
Опыт с моба (`exp`) ванильный, поэтому core-rpg переводит его в свои уровни.

## Команды

Всё под правом `core.mobs.admin` (по умолчанию у операторов). Алиасы: `/cmobs`, `/мобы`.

| Команда | Что |
|---|---|
| `/mobs list` | мобы из mobs.yml (клик — подставить команду призыва) |
| `/mobs spawn <моб> [кол-во] [мир x y z]` | призвать; без координат — туда, куда вы смотрите |
| `/mobs egg <моб> [кол-во] [ник]` | яйцо призыва (ПКМ по блоку) |
| `/mobs drops save\|add <моб>` | лут из инвентаря |
| `/mobs drops list <моб>` | лут с шансами (наведите — предмет, клик — получить) |
| `/mobs drops give <моб> <номер\|all> [ник]` | выдать предмет из лута |
| `/mobs drops remove <моб> <номер>` · `clear <моб>` | убрать предмет / весь лут |
| `/mobs wand` · `/mobs sel info\|undo\|clear` | топорик и выделение |
| `/mobs region create\|redefine <имя>` | регион из выделения / заменить его точки |
| `/mobs region list` · `info\|show\|tp\|delete <имя>` | регионы |
| `/mobs region addmob <имя> <моб> [вес]` · `removemob <имя> <моб>` | кто спавнится |
| `/mobs region set <имя> <параметр> <значение>` | настройки из таблицы выше |
| `/mobs region expand <имя> up\|down <блоков>` | высота |
| `/mobs reload` | перечитать config.yml, mobs.yml, regions.yml и лут |

## Файлы

| Файл | Что |
|---|---|
| `config.yml` | топорик, цвета и плотность частиц, высота и радиус деспавна новых регионов, формат имени |
| `mobs.yml` | мобы (в примере: зомби, скелет-стрелок, ядовитый паук) |
| `regions.yml` | регионы; пишет система, можно править руками и делать `/mobs reload` |
| `drops/<моб>.yml` | лут моба |
