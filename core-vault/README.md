# core-vault — экономика, уровни и физические монеты для Amazake

Система Amazake из трёх модулей, каждый включается в `config.yml` (`modules.economy`, `modules.levels`,
`modules.coins`) и применяется на лету — `/ceco reload`:

- **Экономика.** Баланс игрока (десятичный, точность настраивается, внутри — целые «копейки» в `long`), названия
  валюты в трёх русских формах (1 монета, 2 монеты, 5 монет; дробные — «1,5 монеты»), стартовый и максимальный
  баланс, переводы с подтверждением крупных сумм, топ богатых (считается вне потоков тика), админские команды —
  и для игроков не в сети. Провайдер Vault (`net.milkbowl.vault.economy.Economy`) — либо свой, либо поверх чужого
  (см. «Vault на проде»).
- **Уровни.** Свой уровень и опыт: кривая формулой (`100 * level^1.5`) и/или таблицей, максимальный уровень,
  сообщение/заголовок/звук при новом уровне, награды-команды за уровни (полученный не в сети уровень награждается
  при входе), опыт за мобов (по id моба core-mobs, ванильному типу, «любой враждебный», «любой»), по желанию —
  перевод ванильных сфер опыта. Прогресс — в actionbar, по желанию в босс-баре. **Ванильную полоску опыта не
  трогает**, пока не включено `levels.vanilla-bar: true` (на проде её занимает MMOCore: `override-vanilla-exp: true`).
- **Монеты.** Предмет-монета (по умолчанию подсолнух; материал, `item_model`, имя, описание — в конфиге; метка
  PDC `corevault:coin` со стоимостью одной монеты). Падает с мобов по таблице (шанс, количество min–max,
  стоимость). Поднял — монета **не попадает в инвентарь** (даже полный), предмет исчезает, сумма сразу на балансе,
  звук и actionbar «+3 монеты (баланс: …)». Монеты, оказавшиеся в инвентаре (выданы командой, достали из
  сундука), переводятся на баланс при входе и при клике по ним. Воронки и вагонетки с воронкой монеты не забирают
  (`coins.hoppers-pickup`), мобы не подбирают (`coins.mobs-pickup`). Подсветка и время исчезновения — в конфиге.

## Установка

1. Сборка: `./gradlew azs test` → `build/libs/core-vault.azs` (копия — `dist/core-vault.azs` в корне репозитория).
   Jar API систем (`libs/amazake-systems-api.jar`) скачивается сам или копируется из другой системы.
2. Файл в `systems/` сервера (через временный файл и `mv`), затем `amazake system enable core-vault`
   (обновление — `amazake system restart core-vault`). Появится `systems/core-vault/config.yml`, после первого
   игрока — `players.yml`.
3. Пакет ресурсов не нужен: монета — обычный подсолнух. Своя модель — `coins.item.item-model: "corevault:coin"`
   и ассеты в `pack/assets/corevault/` (общие шейдеры `minecraft/shaders` не трогать).

## Vault на проде (важно)

На проде стоит **Vault 2.1.0 — форк со встроенной экономикой** (`com.example.vault.economy.SimpleEconomy`), он сам
регистрирует провайдер `Economy` с приоритетом **Highest**, хранит ~390 балансов в `plugins/Vault/balances.yml` и
занимает команды `/balance /bal /dinero /pay /pagar /eco /economy /economia /vault /v /vaultop /loan`. MMOCore и
MMOItems цепляются к этому провайдеру при своём включении — **раньше систем**, а магазины DeluxeMenus списывают
деньги командой `[console] eco take %player_name% …` (это `/eco` форка). Других провайдеров экономики на проде
нет (Essentials нет; core-rpg и AmazakeCore экономики не дают; AmazakeTab берёт из Vault только префиксы).

Поэтому `economy.backend`:

| Значение | Что происходит |
|---|---|
| `auto` (по умолчанию) | Есть чужой провайдер (форк Vault) → балансы **у него**: `/money`, `/mpay`, `/ceco`, монеты, плейсхолдеры работают с теми же деньгами, что `/eco` форка, магазины, MMOCore и MMOItems. Свой провайдер не регистрируется — двух экономик нет. Нет чужого → как `internal`. |
| `internal` | Свои балансы в `players.yml`, свой провайдер Vault (прокси интерфейса `Economy`, создаётся в загрузчике Vault) с приоритетом `economy.vault.priority` (по умолчанию **High**). При форке на Highest приоритет High **проигрывает**; Highest — равный, но плагины, взявшие провайдера при своём старте (MMOCore, MMOItems), всё равно останутся на форке до рестарта, а `/eco` в меню — это команда форка. Включать только при переходе: `/ceco import vault` → убрать встроенную экономику форка → рестарт. |
| `vault` | Только чужой провайдер; если его нет — предупреждение и свои балансы. |

`/ceco import vault [replace]` переносит `plugins/Vault/balances.yml` (раздел `balances`) в `players.yml` (без
`replace` — только счета, которых нет или у которых стартовый баланс). Порядок перехода на свои балансы:
`backend: internal` → `/ceco reload` → `/ceco import vault replace` → замена Vault-форка на обычный Vault 1.7.3
(или выключение его экономики) → рестарт → магазины DeluxeMenus перевести с `eco take` на `ceco take`.

`/ceco info` показывает, где сейчас балансы и кто главный провайдер Vault.

## Команды

Плагины регистрируют команды раньше систем и выигрывают при совпадении имён, поэтому основные имена выбраны
свободными, а привычные — алиасами (работают, только где их не занял плагин).

| Команда | Алиасы | Кто | Что |
|---|---|---|---|
| `/money [игрок]` | `/balance` `/bal` (на проде заняты Vault), `/деньги`, `/баланс` | все | баланс свой/чужой |
| `/mpay <игрок> <сумма>` | `/pay` (на проде занят Vault), `/перевести` | игроки | перевод; от `pay.confirm-above` — подтверждение `/mpay confirm`; нельзя себе, меньше `pay.min`, отрицательные; офлайн — по `pay.offline` |
| `/moneytop [стр.]` | `/baltop`, `/mtop` | все | топ богатых (кэш, `top.refresh-seconds`) |
| `/ceco give\|take\|set\|reset <игрок> <сумма>` | `/eco` (на проде занят Vault), `/corevault` | `corevault.admin` | изменить баланс, и офлайн |
| `/ceco drop <кол-во> [x y z [мир]]` | | `corevault.admin` | выбросить монеты (без координат — под собой) |
| `/ceco coin <игрок> <кол-во> [стоимость]` | | `corevault.admin` | монеты предметом в инвентарь |
| `/ceco import vault [replace]` · `/ceco info` · `/ceco reload` | | `corevault.admin` | импорт из Vault 2.x, состояние, перечитать |
| `/level [игрок]` · `/level top [стр.]` | `/lvl`, `/уровень` | все | уровень и опыт |
| `/level give\|take\|set <игрок> exp\|levels <кол-во>` | | `corevault.admin` | опыт/уровни, и офлайн |

`/level … exp`: give/take — добавить/снять опыт с переходом через уровни (вниз тоже), set — весь опыт с начала.
`… levels`: give/take — сдвинуть уровень (опыт внутри уровня сохраняется), set — уровень с нулём опыта.
Суммы: `10`, `10.5`, `10,50`, `1 000`, `1_000`, `1.5k`, `2m`; знаков после запятой — не больше `decimals`.
Проверено, что `/money /mpay /moneytop /ceco /level /lvl` на проде свободны: MMOCore (`/player /attributes /stats
/mmoclass /waypoints /quests /skills /friends /party /guild /withdraw /deposit /skilltrees /pvpmode /cast`),
RoyalQuestClasses (`/class /profession /myclass /stats /rqadmin`), MMOItems, DeluxeMenus (`/menu /maped
/shop_mounts /shop_pets`), AmazakeCore — `/level` ни у кого нет.

## Плейсхолдеры (PlaceholderAPI)

`%corevault_balance%` (число `123.45`), `_balance_formatted` (`123,45 монеты`), `_balance_short` (`123,45`),
`_currency_singular/_genitive/_plural`, `_level`, `_exp`, `_exp_needed`, `_exp_total`, `_progress` (процент),
`_max_level`, `_top_<n>_name`, `_top_<n>_value` (с названием), `_top_<n>_value_raw`, `_leveltop_<n>_name`,
`_leveltop_<n>_value`. Выключенный модуль — пустая строка. Мост — как в core-effects/core-npc (класс-наследник
`PlaceholderExpansion` ресурсом `papi-bridge/*.bin`, загружается в потомке загрузчика PlaceholderAPI).

## Настройка (кратко)

Всё с комментариями — в `config.yml`. Главное: `economy.currency.*` (точность, названия, разделители, шаблон
`{amount} {name}`), `economy.start-balance`, `max-balance`, `pay.*`, `top.*`, `vault.*`; `levels.curve.formula`
(`+ - * / % ^`, скобки, `floor ceil round sqrt abs ln log10 min max`), `levels.curve.table`, `levels.max-level`,
`levels.level-up.*` (`commands` — на каждый уровень), `levels.rewards."<уровень>"`, `levels.sources.mobs`
(`core-mobs` → id моба, `types`, `hostile`, `default`; число или `min-max`), `spawner-multiplier`,
`vanilla-orbs`; `coins.value`, `coins.item.*`, `coins.entity.*`, `coins.drops` (те же уровни поиска, что у опыта;
правило `{chance: 50, amount: 1-2, value: 5}`), `from-spawners`, `require-player-kill`. Смена `decimals` на лету
пересчитывает балансы. Модуль `coins` без `economy` не работает (монеты тогда — обычные подсолнухи).

## Как устроено

- **Хранение.** Все счета (и офлайн) — в памяти (`ConcurrentHashMap`), файл `players.yml` (UUID → имя, баланс
  десятичной строкой, уровень, опыт, невыданные награды). Читается один раз при включении системы; запись —
  снимком во временный файл и переименованием поверх (атомарно), в асинхронной задаче раз в
  `storage.save-interval-seconds`, если были изменения, и всегда при выключении системы.
- **Атомарность.** Операции со счётом — под замком счёта; перевод берёт оба замка в порядке UUID; уровни и опыт
  меняются под тем же замком. Vault может звать из любого потока (проверено 1000 асинхронными пополнениями).
  Внешний провайдер Vault: операции core-vault последовательны, «задать» = снять/добавить разницу, перевод =
  снять + зачислить (при отказе — возврат).
- **Потоки.** Игрок (инвентарь, actionbar, заголовок, звук, босс-бар, ванильная полоска) — только в его потоке
  (`runOnceForPlayer`/`runForPlayer`); смерть моба, выпадение и подбор монет, воронки — поток региона (их
  события; `/ceco drop` — `RegionScheduler` по точке); награды-команды, reload, провайдер Vault — глобальный
  поток; запись файла, топ, импорт — асинхронно. Планировщик сущностей не используется.
- **Уборка при выключении.** Задачи отменяет ядро; снимаются провайдер Vault и расширение PlaceholderAPI,
  убираются босс-бары (в потоке игрока), счета записываются. Команды и слушатели снимает ядро.

## Проверено (mc-test, mineflayer: `/home/user/mc-bot/v1_vault.js` … `v6_bars.js`)

give/take/set онлайн и офлайн, отказ при нехватке, отрицательных и лишних знаках; `/money` свой и чужой,
`/mpay` (себе нельзя, минимум, нехватка, подтверждение, офлайн-получатель), `/pay` алиас без Vault; `/moneytop`,
`/baltop`, `%corevault_top_1_name%`; новый уровень — сообщение и команда-награда, награда офлайн-игроку при
входе, give/take/set exp/levels; зомби → 3 монеты → подобраны на баланс, в инвентаре нет, actionbar «+3», опыт
за моба; воронка монеты не взяла, игрок поднял с воронки; монеты предметом → на баланс при входе; рестарт
сервера — всё сохранилось; модули выкл/вкл через reload; `amazake system disable/enable/restart` — команды и
плейсхолдеры снимаются, файл записан, всё возвращается. С продовым Vault 2.1.0 (форк): `auto` → балансы у форка,
`/eco` форка и `/ceco` видят одни деньги, `/balance` отвечает форк, монеты и переводы идут в баланс форка. Со
своим провайдером (`internal`, тестовый плагин-потребитель): баланс/пополнение/списание/отказы/по имени/банки
NOT_IMPLEMENTED/асинхронные вызовы/новый счёт; провайдер снимается при выключении и возвращается при включении.
Босс-бар и зеркало ванильной полоски.
